# Buddy Extension

Independent implementation of the Team AI Conversation Cloud browser extension.

## Goal

Capture conversations from supported AI websites, normalize them into a common format, persist them offline, and synchronize them reliably with the project backend while protecting credentials and team data.

## Supported platform targets

- ChatGPT
- Claude
- Gemini
- Grok
- DeepSeek
- Perplexity

## Development rule

This is a new implementation. It does not copy source files from the original or earlier copy unless a design decision is intentionally reimplemented and documented.
